# Voice Monitor

Dashboard voor de voice-assistent van Woonboulevard Wijchen (PWA), gepubliceerd via GitHub Pages.

Instellingen (API-sleutels, webhooks) staan alleen per apparaat in de browser, nooit in deze repository.

`apps-script-orderlijst.gs.txt` is een kopie van het Google Apps Script in het ai@-account dat de status van de orderlijst teruggeeft.
